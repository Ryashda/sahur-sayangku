🌙 Juragan Sahur: Misi Penyelamatan Imsak! 📢

"Game spesial buat ayang biar bangun sahurnya semangat dan nggak lemes! Jangan sampai warga kesiangan, apalagi bikin Pak RT ngamuk!"

Juragan Sahur adalah game Time Management / Whack-a-Mole interaktif dengan kearifan lokal edisi Ramadhan. Tugas pemain adalah menjadi "Agen Sahur Utama" yang harus membangunkan warga komplek sebelum waktu Imsak (60 detik) habis, menggunakan alat yang tepat!

🎮 Cara Bermain (Rules)

Perhatikan icon yang muncul di atas rumah warga. Cocokkan senjata/alat di bawah layar dengan tipe warga yang sedang tidur. Tap/Klik rumah tersebut untuk membangunkan mereka!

✨ Fitur Unggulan

⏱️ Timer Deg-degan: Waktu 60 detik yang makin berdebar saat mendekati angka 10.

⏸️ Fitur Jeda (Pause): Tiba-tiba dipanggil emak buat makan beneran? Santai, game bisa di-pause!

🎵 Musik & Efek Suara: Dilengkapi Background Music asik dan Sound Effects konyol (suara panci jatuh, kentongan, dll) untuk setiap interaksi.

📱 Responsif: Enak dimainin di HP maupun di Laptop/PC.

🚀 Cara Menjalankan Game (Instalasi)

Karena game ini dibungkus dalam satu komponen React interaktif, cara menjalankannya sangat mudah:

Pastikan kamu punya environment React (misal: Vite atau Create React App).

Copy-paste kode sahur_game.jsx ke dalam project kamu (jadikan sebagai App.jsx atau komponen utama).

Pastikan Tailwind CSS sudah ter-install dan terkonfigurasi di project kamu.

[PENTING] Audio BGM: Siapkan file lagu mp3 kesukaan kalian berdua, ubah namanya menjadi sayang.mp3, dan letakkan di dalam folder public project kamu.

Jalankan npm run dev atau npm start.

Kasih link-nya ke ayang!
